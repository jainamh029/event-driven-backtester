Event-Driven Backtester

A new price arrives, the strategy emits a signal, an order goes out and it fills with costs, one event at a time. Because components can only talk through a single queue, a strategy never gets to peek at tomorrow.

Open the live dashboard View on GitHub Jump to results See the look-ahead bug

How it works

Five event types, four components, one queue. Nothing calls anything else directly.

The timing rule that prevents look-ahead

  1. Bar t opens (MARKET): orders placed yesterday fill at today's open, plus slippage and commission.
  2. Bar t closes (BAR_CLOSE): the portfolio marks to market; the strategy may use bars up to and including t.
  3. The strategy emits a SIGNAL; the portfolio sizes it and emits an ORDER; execution holds it until bar t+1 opens.

So a decision can never be filled at a price that was used to make it. The DataHandler owns the full dataset but only has methods that return rows up to the current bar, and the test-suite checks the property directly: truncate or corrupt every bar after k and the results up to k don't change.

Vectorized vs event-driven

  

    

      
VectorizedEvent-driven

      
SpeedWhole series in one passOne bar at a time, so slower (this site's sweeps still run in seconds)

      
Look-aheadEasy to introduce with one missing shift(1)Structurally prevented: strategies only get history up to now

      
ExecutionApproximated (close-to-close, flat costs)Orders, next-open fills, slippage, commission, buying-power limits

      
Live tradingDifferent code pathSame loop; swap the simulated broker for a real one

      
Best forQuick idea screeningValidating anything you might trade

    

  






  
Run it yourself


git clone https://github.com/jainamh029/event-driven-backtester
cd event-driven-backtester
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

python -m evbt --strategy sma --symbol SPY      # one backtest
pytest                                          # incl. the causality tests
python scripts/build_report.py                  # regenerate this page
